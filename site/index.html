SkyMob apt repository

Signed Debian package channel for the SkyMob edge appliances.

Carries skbridge, the LAN↔cloud bridge appliance, and skprinter, the label printer service that runs alongside it — both for amd64 (virtual machines) and arm64 (the physical appliance). Requires Debian 13 (trixie).

Install

sudo apt install -y curl
sudo install -d /etc/apt/keyrings
sudo curl -fsSL https://apt.skymob.app/skymob.asc -o /etc/apt/keyrings/skymob.asc
sudo tee /etc/apt/sources.list.d/skymob.sources >/dev/null <<'EOF'
Types: deb
URIs: https://apt.skymob.app
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/skymob.asc
EOF
sudo apt update
sudo apt install skbridge skprinter

Install only what the appliance needs; the two are independent and coexist. Every later upgrade is sudo apt upgrade.
